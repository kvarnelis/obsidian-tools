Obsidian Tools

Plugins for Obsidian. Install each separately.

Requirements and installation methods differ by plugin. Download links below point to published releases.

Install an Obsidian plugin

Open Settings → Community plugins and, if prompted, choose Turn on community plugins to leave Restricted mode.

For plugins in Obsidian’s community directory, open Settings → Community plugins → Browse, find the plugin, then install and enable it. Composition Mode is listed there.

For Pocket Codex, follow the manual steps below. Paragraph Numbers and Composition Mode use the same process with their three files and folder names listed under each plugin:

  1. Open Pocket Codex’s release page and download all four files: main.js, manifest.json, styles.css, and pocket-codexd.cjs. Download the release assets rather than GitHub’s source-code archive.
  2. In your vault, create .obsidian/plugins/pocket-codex/. The .obsidian folder may be hidden in your file manager.
  3. Put the downloaded files directly in that folder. Restart Obsidian, open Settings → Community plugins, and enable the plugin.
  4. Complete the plugin’s setup below.

Obsidian’s community plugin guide

Pocket Codex

Use Claude Code, Codex, or Grok in an Obsidian sidebar, with conversations, file context, edits, and provider tools. Built on Claudian and maintained independently.

Requires Obsidian 1.7.2 or later. Install and sign in to the command-line program for your chosen provider, then configure its location in Pocket Codex settings. Pocket Codex is not currently in Obsidian’s community directory.

Download main.js, manifest.json, styles.css, and pocket-codexd.cjs from the release below. Place all four files in .obsidian/plugins/pocket-codex/, restart Obsidian, and enable Pocket Codex. Open it from the ribbon or command palette and choose a provider.

Optional iPhone and iPad remote access requires additional setup on a Mac and Tailscale on both devices. Follow the mobile setup instructions. If you used Claudian Praetor, follow the migration guide and disable the old plugin before enabling Pocket Codex.

Composition Mode

Write in a paper-style editor with page sizes, margins, type controls, zoom, and page breaks.

Requires Obsidian 1.5.0 or later on desktop. Install through Settings → Community plugins → Browse and search for Composition Mode, or download main.js, manifest.json, and styles.css from its release and put those three files in .obsidian/plugins/composition-mode/.

Run Composition Mode: Toggle from the command palette. The bottom control bar adjusts the layout. Pagination is an editor aid rather than a print typesetter; the plugin is experimental and has mainly been tested with the Minimal theme.

Paragraph Numbers

Show paragraph numbers in the editor gutter for referring to passages in long-form prose.

Requires Obsidian 1.0.0 or later; its manifest supports desktop and mobile. Download main.js, manifest.json, and styles.css from the release below and put those three files in .obsidian/plugins/paragraph-numbers/. Restart Obsidian and enable Paragraph Numbers under Community plugins. It is not currently listed in Obsidian’s community directory.

Turn off Obsidian’s built-in line numbers under Settings → Editor.
