# Obsidian Tools

A static directory of independently installed Obsidian plugins.

Published page: https://kvarnelis.github.io/obsidian-tools/

The page links to Pocket Codex, Composition Mode, and Paragraph Numbers. Requirements, release downloads, manual installation, and source links are listed for each.

Built with plain HTML and CSS. There are no scripts, analytics, external fonts, screenshots, or generated vault indexes. GitHub Pages serves the repository root from the `main` branch.

Related: [Zotero Tools](https://kvarnelis.github.io/zotero-tools/).
